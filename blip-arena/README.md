# Blip Arena

2~6인 탑뷰 실시간 멀티플레이 슈팅 게임 (핵심 뼈대 버전)

## 실행

```bash
cd blip-arena
npm install
npm start
```

- 이 컴퓨터: http://localhost:3000
- 같은 와이파이의 친구: 서버 실행 시 콘솔에 출력되는 `http://192.168.x.x:3000` 주소
  (처음 실행 시 Windows 방화벽 허용 창이 뜨면 "허용")

## 혼자 테스트 (탭 여러 개)

1. 탭 A에서 닉네임 입력 → **방 만들기** → 4자리 코드 확인
2. 탭 B, C…에서 다른 닉네임 + 코드 입력 → **참가**
3. 탭 A(방장)에서 **게임 시작**
4. 탭을 나란히 띄워 두면 서로의 움직임과 피격을 동시에 볼 수 있음

> 같은 브라우저 탭끼리는 닉네임 저장소를 공유하므로 참가 전에 닉네임만 바꿔 주세요.
> 백그라운드 탭은 브라우저가 프레임을 멈추므로, 창을 나란히 배치하는 걸 추천합니다.

## 랙 테스트

| 방법 | 예시 | 효과 |
|---|---|---|
| 특정 탭만 | `http://localhost:3000/?lag=150&jitter=50` | 이 탭의 송신/수신이 각각 150~200ms 지연 |
| 서버 전체 | `npm run lag` (100ms + 지터 30ms) | 모든 접속자에게 지연 |
| 서버 수치 지정 | `node server/index.js --lag=200 --jitter=80` | 원하는 값으로 |

- 좌측 상단에 핑이 표시됩니다. `lag=150`이면 왕복 300ms 이상이 나옵니다.
- 게임 중 **F2**: 디버그 표시. 빨간 원은 서버가 확정한 내 위치, 노란 원은 보간 전 다른 플레이어의 최신 서버 위치입니다.
  랙을 줘도 내 캐릭터는 즉시 움직이고 빨간 원이 뒤따라오며, 다른 플레이어는 노란 원보다 조금 뒤에서 부드럽게 따라가면 정상입니다.

## 모바일

휴대폰 브라우저로 같은 와이파이 주소(`http://192.168.x.x:3000`)에 접속하면 됩니다. 터치 기기는 자동으로 감지되어 가상 조이스틱이 나옵니다. 가로 화면을 권장합니다.

| 조작 | 동작 |
|---|---|
| 화면 왼쪽 아무 곳이나 누르고 끌기 | 이동 (누른 자리에 조이스틱이 생김) |
| 오른쪽 아래 공격 버튼 끌기 → 놓기 | 끈 방향으로 조준 후 발사. 투척수는 끈 거리가 던지는 거리 |
| 공격 버튼 톡 치기 | 가장 가까운 적 자동 조준 (기지전은 적 기지 포함) |
| 끌었다가 가운데로 되돌려 놓기 | 발사 취소 |
| 필살기 버튼 (게이지가 차면 노란색) | 공격 버튼과 같은 방식 |
| 위쪽 채팅 / 팀 채팅 버튼 | 채팅 입력 (보내기 버튼 또는 키보드 엔터) |

- **PC에서 모바일 화면 테스트**: 주소 끝에 `?mobile=1`을 붙이거나, 크롬 개발자 도구(F12) → 기기 툴바(Ctrl+Shift+M)에서 휴대폰을 고르고 새로고침합니다. 반대로 `?mobile=0`은 터치 기기에서도 PC 조작을 강제합니다.
- 화면이 작으면 카메라가 자동으로 조금 축소되어 주변이 더 넓게 보입니다.

## 효과음과 연출

- **효과음**: 음원 파일 없이 브라우저에서 직접 합성합니다(`public/js/Sound.js`). 발사, 폭발, 피격, 처치, 필살기 준비, 큐브 획득, 승리 등이 있고, 멀리서 난 소리일수록 작게 들립니다. 왼쪽 위 **소리 켬/끔** 버튼으로 끌 수 있고, 설정은 브라우저에 저장됩니다. 브라우저 정책 때문에 화면을 한 번 누르거나 키를 눌러야 소리가 나기 시작합니다.
- **피격**: 맞으면 맞은 양에 비례해 화면이 흔들리고 가장자리가 붉게 번쩍입니다. 휴대폰에서는 진동도 옵니다(안드로이드).
- **처치**: 쓰러진 자리에 파편이 터집니다. 내가 처치하면 "처치!" 배너와 짧은 카메라 줌이 나오고, 죽지 않고 계속 처치하면 "2연속 처치!", "3연속 처치!"로 바뀝니다. 내가 당하면 "OO에게 처치당함"이 나옵니다.

## 캐릭터

대기실에서 고릅니다. 경기 중에는 바꿀 수 없습니다.

| 캐릭터 | 역할 | 일반 공격 | 필살기 |
|---|---|---|---|
| 고르보 | 탱커 (체력 180, 느림) | 부채꼴 산탄 5발, 근거리 | **대지 강타**: 주변 적에게 피해를 주고 밀쳐냄 |
| 니아 | 저격수 (체력 70) | 장거리 단발 고데미지 | **관통 레일**: 벽과 적을 모두 꿰뚫는 탄 |
| 토트 | 투척수 (체력 90) | 벽을 넘는 포물선 폭탄, 범위 피해 | **불꽃 융단**: 목표 지점 주변에 폭탄 5개 |

- 적을 맞힐 때마다 필살기 게이지가 찹니다. 필살기로 준 피해로는 게이지가 차지 않습니다.
- 게이지가 가득 차면 캐릭터 둘레에 노란 링이 깜빡입니다. 적도 이 링을 볼 수 있습니다.
- 수치는 전부 `shared/characters.json`에 있습니다. 파일 맨 위 `_안내`에 각 항목 설명이 있습니다.
- 새 캐릭터를 추가하려면 JSON에 항목을 복사해 수치만 바꾸면 됩니다. 이때 공격/필살기 `type`은 기존 것(spread/bullet/lob, shockwave/rail/barrage) 중에서 골라야 합니다. 새 캐릭터의 도형은 기본 원으로 나옵니다.

## 게임 모드

방장이 대기실에서 고릅니다.

| 모드 | 규칙 |
|---|---|
| 데스매치 | 3분 동안 킬이 가장 많은 사람이 승리. 죽으면 3초 후 부활 |
| 배틀로얄 | 부활 없음. 마지막 1명이 남으면 승리. 결과 화면에 생존 순위 표시 |
| 기지전 | 2팀으로 나눠 상대 기지(포탑)를 먼저 부수는 팀이 승리. 5분이 지나면 기지 체력 비율이 높은 팀 승리 |

기지전 세부 규칙:
- **팀 나누기**: 대기실에서 방장이 화살표 버튼으로 한 명씩 옮기거나 **자동 나누기**를 누릅니다. 새로 들어온 사람은 인원이 적은 팀에 들어갑니다. 두 팀 인원이 같아야 시작할 수 있습니다(2vs2, 3vs3. 혼자 테스트할 때는 1vs1 가능).
- **기지와 포탑**: 기지는 이동과 총알을 막는 구조물입니다. 포탑은 사거리(원으로 표시) 안의 가장 가까운 적을 자동으로 쏩니다. 수풀에 숨은 적은 포탑도 보지 못합니다. 저격수는 포탑 사거리 밖에서 기지를 칠 수 있습니다.
- **아군 피해 없음**: 아군의 총알, 폭발, 충격파는 아군과 아군 기지에 피해를 주지 않습니다. 총알은 아군을 그냥 통과합니다.
- **체력바 색**: 나는 초록, 아군은 파랑, 적은 빨강입니다. 기지도 우리 기지는 파랑, 적 기지는 빨강입니다.
- **수풀**: 같은 팀끼리는 수풀 속에 있어도 항상 보입니다.
- **부활**: 4초 뒤 내 기지 근처에서 부활합니다.
- **팀 채팅**: `T`로 팀 채팅을 열고, 채팅 중 `Tab`으로 전체/팀을 바꿉니다. 팀 메시지는 서버가 같은 팀에게만 보내므로 상대 팀 브라우저에는 아예 도착하지 않습니다.
- 수치(기지 체력, 포탑 사거리/데미지/연사, 시간 제한, 팀 이름)는 `shared/config.js`의 `teams` 항목에서 바꿉니다. 기지 위치는 맵 JSON의 `bases`로 정합니다.

배틀로얄 세부 규칙:
- **독가스**: 30초 후부터 맵 가장자리에서 안전 구역이 줄어듭니다. 안전 구역 밖에 있으면 1초마다 15 데미지를 받고, 완전히 닫히면 30 데미지를 받습니다. 독가스 안에 있으면 화면에 경고가 뜹니다.
- **파워 큐브 상자** (보라색): 부수면 파워 큐브가 나옵니다. 큐브를 먹을 때마다 최대 체력이 +12%(늘어난 만큼 바로 회복), 공격력이 +10% 늘어납니다. 죽으면 갖고 있던 큐브를 그 자리에 떨어뜨립니다.
- **관전**: 탈락하면 나를 쓰러뜨린 사람을 관전합니다. ← → 키나 클릭으로 다른 생존자로 바꿀 수 있습니다. 관전 화면은 그 사람의 시야와 같아서, 그 사람에게 안 보이는 수풀 속 적은 관전자에게도 안 보입니다.
- 경기 중에 들어온 사람은 관전자로 참가합니다.
- 혼자 시작하면(테스트용) 내가 탈락하는 순간 끝납니다.
- 수치는 `shared/config.js`의 `battleRoyale` 항목에서 조절합니다. 상자 위치는 맵 JSON의 `powerBoxes`로 정하고, 없으면 무작위로 배치합니다.

## 맵

방장이 대기실에서 맵을 고릅니다. 맵은 `shared/maps/` 폴더에 있습니다.

| 요소 | 동작 |
|---|---|
| 벽 (회색) | 이동과 총알을 막음 |
| 부서지는 벽 (나무 상자) | 총알, 폭발, 필살기로 피해를 받다가 내구도가 0이 되면 사라짐. 금이 간 정도로 남은 내구도 표시 |
| 수풀 (초록) | 안에 들어가면 적에게 안 보임. 단, 아래 경우에는 보임: 같은 수풀 안에 있음 / 110px 이내로 가까움 / 방금 공격했거나 맞음(1초) |

- **수풀 숨김은 서버가 판정합니다.** 보이지 않는 적은 위치 정보 자체를 클라이언트에 보내지 않으므로 개발자 도구로 엿볼 수 없습니다.
- 수치는 `shared/config.js`의 `bush`, `world` 항목에서 조절합니다. (드러나는 거리, 공격 후 드러나는 시간, 벽 기본 내구도)

### 새 맵 추가하기

1. `shared/maps/arena.json`을 복사해 `shared/maps/<원하는id>.json`으로 저장 (파일 이름이 맵 id)
2. `name`, `description`과 사각형 좌표를 수정
3. 서버 재시작 → 대기실 맵 목록에 미리보기와 함께 나타남

```jsonc
{
  "name": "맵 이름",
  "description": "설명",
  "width": 1600, "height": 1200,
  "breakableHp": 120,                       // (선택) 부서지는 벽 기본 내구도
  "walls":      [{ "x": 0, "y": 0, "w": 100, "h": 40 }],
  "breakables": [{ "x": 0, "y": 0, "w": 100, "h": 40, "hp": 200 }],  // hp는 선택
  "bushes":     [{ "x": 0, "y": 0, "w": 150, "h": 150 }],  // 겹치거나 맞닿은 사각형은 같은 수풀
  "spawnPoints":[{ "x": 80, "y": 600 }],   // (선택) 없으면 무작위 위치에서 부활
  "powerBoxes": [{ "x": 800, "y": 460 }],  // (선택) 배틀로얄 파워 큐브 상자 중심 위치. 없으면 무작위
  "gasCenter":  { "x": 800, "y": 600 },    // (선택) 독가스가 좁혀 들어갈 중심. 없으면 맵 중앙
  "bases":      [{ "x": 800, "y": 70 }, { "x": 800, "y": 1130 }]  // (선택) 기지전 1팀/2팀 기지 중심. 없으면 왼쪽/오른쪽 가운데
}
```

형식이 틀린 맵은 서버 콘솔에 이유를 출력하고 건너뜁니다. 서버는 그대로 실행됩니다.

## 구조

```
server/index.js         Express + Socket.IO, 랙 옵션
server/RoomManager.js   방 코드, 참가/퇴장
server/Room.js          30틱 게임 루프 (서버 권위 판정 전부, 수풀 시야 판정, 받는 사람별 스냅샷)
server/maps.js          shared/maps/*.json 읽기 + 형식 검사
shared/characters.json  ★ 캐릭터별 수치 (체력/속도/무기/필살기)
shared/config.js        ★ 공통 수치 (회복/부활/경기 시간/수풀/네트워크)
shared/maps/*.json      ★ 맵 데이터 (벽/부서지는 벽/수풀/부활 위치)
shared/world.js         맵 JSON → 현재 맵 상태 (부서진 벽 반영, 수풀 묶기)
shared/physics.js       이동/충돌 (서버와 클라이언트 예측이 같이 씀)
shared/lag.js           인위적 지연기
public/js/GameScene.js  예측/보정/보간 (상단 주석에 원리 설명)
public/js/PlayerView.js 캐릭터 그래픽 + 조준 가이드 (스프라이트 교체 지점)
public/js/ProjectileView.js  총알/폭탄/이펙트 그래픽 (스프라이트 교체 지점)
public/js/HUD.js        순위표, 킬 로그, 채팅, 타이머, 필살기 게이지, 피격/킬 배너
public/js/TouchControls.js  모바일 가상 조이스틱 + PC/모바일 감지
public/js/Sound.js      효과음 (Web Audio 합성. 음원으로 바꿀 곳)
public/js/lobby.js      로비 화면 흐름, 캐릭터 선택
```

## 혼자 테스트할 때 참고

`shared/config.js`의 `match.minPlayersToStart`가 1로 되어 있어 혼자서도 시작할 수 있습니다. 실제로 할 때는 2로 바꾸세요.
